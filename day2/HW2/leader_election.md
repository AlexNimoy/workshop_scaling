# Consul для Leader Election

## Преимущества

1. Отказоустойчивость: Consul имеет встроенную поддержку консенсуса через алгоритм Raft, обеспечивая надёжный Leader Election даже при сбоях узлов.

2. Sessions API: Consul предоставляет механизм сессий с автоматическим освобождением блокировок при истечении TTL или падении узла что важно для работы Leader Election.

3. Целевое назначение: Consul специально создан для сервис-дискавери и координации распределённых систем.

4. Интеграция: Consul уже в приложении (Diplomat)

5. Сохранение интерфейса: Новая реализация сохраняет тот же интерфейс (метод `leader?`), но обеспечивает более надёжный выбор лидера.

## Техническая реализация

Реализация использует:

- Сессии Consul с автоматическим удалением при истечении TTL
- Блокировки key-value хранилища для атомарного получения лидерства
- Механизм обновления сессий для поддержания лидерства
- Корректную обработку ошибок при работе с Consul API
